# Publication provenance

This public course repository is initialized on 2026-10-20 as retrospective
research-evidence recovery. Its first remote commit is a publication bootstrap
document; the subsequent source import brings the already existing Baseline,
MLP and single-factor variants together. It does not simulate a historical
Baseline-then-improvement development sequence.

All recovered experiments remain `pre-git experiment`, with execution commit
UNKNOWN. Current import hashes must never be assigned retroactively to them.
Local recovery-development commits are retained separately from the published
branch. No earlier history is reset, rebased or force-pushed.

Normal noninteractive Git HTTPS push could not obtain a username credential.
The already authorized GitHub connector is used for safe Git-object publication;
no token is extracted or printed. The complete remote tree is to be read back
with Git and compared with the scanned local tree. The final verification record
and actual published commits identify what was uploaded.

Data, weights, predictions, secrets and private absolute paths are excluded.
Scientific source copies, MIT notices, evidence limitations and pending human
course requirements remain explicit.

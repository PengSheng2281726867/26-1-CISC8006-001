# Historical source archive

Byte-identical code/report copies from the existing research, stored as text so they are not mistaken for current execution entry points. Original relative-path assumptions and legacy behavior remain unchanged. Use the course scripts documented in the root README to run models. The archive preserves the actual old training, evaluation, analysis, verification, plotting and version notes for auditing. Execution Git commits are UNKNOWN; archival/import hashes do not repair that historical gap.

All sources are covered by the retained GAMMA MIT notice or are authorized derivative research work. No nested Git history, data or weights are copied. See source_manifest.json for source-to-copy hashes.

def digest(path):
    return sha256(path.read_bytes()).hexdigest()


def load(path):
    path = Path(path).resolve()
    OBSERVED.setdefault(path, (digest(path), path.stat().st_mtime_ns))
    return json.loads(path.read_text(encoding='utf-8'))


def table(headers, rows):
    return ('| ' + ' | '.join(headers) + ' |\n| ' + ' | '.join(['---'] * len(headers))
            + ' |\n' + ''.join('| ' + ' | '.join(map(str, row)) + ' |\n' for row in rows))


def signed(value):
    return '0.00' if abs(value) < 1e-9 else f'{value:+.2f}'


def describe(values):
    return f'{100 * mean(values):.2f} ± {100 * stdev(values):.2f}'


def close(left, right):
    assert math.isclose(left, right, rel_tol=1e-9, abs_tol=1e-9), (left, right)


def exact_p(differences):
    observed = abs(sum(differences))
    return sum(abs(sum(s * d for s, d in zip(signs, differences))) >= observed - 1e-10
               for signs in product((-1, 1), repeat=len(differences))) / (2 ** len(differences))


def holm_values(ps):
    result = [0.0] * len(ps)
    running = 0.0
    for rank, index in enumerate(sorted(range(len(ps)), key=ps.__getitem__)):
        running = max(running, min(1.0, (len(ps) - rank) * ps[index]))
        result[index] = running
    return result

## 3. 五种方法实际改了什么

| 方法 | 融合/Agreement | Scorer参数 | 相对Dot新增参数 |
| --- | --- | --- | --- |
| Uniform | 关闭动态routing，各hop等权融合 | 0 | 0 |
| Dot | `sum(hop * fused, dim=-1)` | 0 | 0 |
| MLP-ReLU | `Linear(64,32) → ReLU → Linear(32,1)` | 2,113 | 2,113 |
| MLP+LN | `Linear(64,32) → LayerNorm(32) → ReLU → Linear(32,1)` | 2,177 | 2,177 |
| MLP-GELU | `Linear(64,32) → GELU → Linear(32,1)` | 2,113 | 2,113 |

Dot和三种MLP均保留 `b=b+agreement`、沿hop维softmax、加权融合、squash、原始routing循环、最终bias和分类头。所有节点、hop及routing轮次共享一个scorer。Dot/MLP输入为hop `[N,P,32]` 和fused `[N,32]`；MLP拼接输入 `[N,P,64]`，输出 `[N,P]`。

LN仅归一化scorer的32维隐藏向量（eps=1e-5，affine=True）；GELU仅替换ReLU，没有同时加入LN，也没有新增softmax、温度、残差或hop特征网络。原GAMMA特征层的LayerNorm在各组均保留。

**这些评分网络并不把分数“不断缩放到1”。** Score可以为任意实数；原有softmax将各hop系数变为非负且和为1。squash对融合向量的幅度进行非线性压缩，与hop系数归一化是不同步骤。Uniform关闭的是动态routing，仍保留可学习hop通道缩放、特征LayerNorm及squash。

## 4. 可比主实验协议

| 项目 | 统一设置 |
| --- | --- |
| 数据集 | Texas、Wisconsin、Cornell、Chameleon、Squirrel、Actor |
| 最大hop K | 1、2、3、4；Uniform只完成K2–4 |
| 实际powers | `[0,...,K]`，包含0-hop，P=K+1 |
| 消息传递层 | 真正1个GAMMA层，加Linear分类头；`num_layers=2` |
| Routing / 隐藏维度 | R=2；D=32；MLP隐藏维度32 |
| 划分 | 相同持久化60/20/20整数划分；划分种子102–111 |
| 训练随机性 | 每Split训练seed42–51；共有初值及CPU/CUDA随机状态配对 |
| 优化器 | Adam，lr=0.02，weight_decay=1e-4，梯度裁剪1 |
| Dropout | 输入0.2，隐藏0.8 |
| 预算 / 模型选择 | 最多500 epoch；早停patience50；只用验证集选最佳权重，深拷贝保存 |
| 调度器 | ReduceLROnPlateau，factor0.5，patience50，min_lr1e-6 |
| 确定性 | 严格确定性算法；关闭TF32；CUBLAS_WORKSPACE_CONFIG=:4096:8 |

较小K从同一个随机K4模板截取共有hop初值；这是未训练初始化，不是预训练。LN/GELU的两个Linear和全部共有GAMMA参数与原MLP一一对齐；LN额外gamma=1、beta=0。每种方法分别训练并保存自己的最佳Checkpoint，没有以测试集选K、选epoch或为单一方法调参。

K是最大传播范围，不是GAMMA层数或routing轮数。原代码各分支从头传播，因此K1/2/3/4的传播调用总数是1/3/6/10，最长分支仍只有K步。p-hop表示p步游走，不仅是最短距离恰好为p的邻居。

### K交互的准确解释

Actor上GELU−MLP：K1为{signed(delta('Actor', 1, 'mlp_gelu', 'mlp'))} pp，K3为{signed(delta('Actor', 3, 'mlp_gelu', 'mlp'))} pp。逐Split的“两个差值再相减”在10对中均为正，平均{signed(interaction['delta_mean_pp'])} pp，未校正配对t的95%区间[{signed(interaction['ci95_low_pp'])}, {signed(interaction['ci95_high_pp'])}]，双侧精确符号翻转p={interaction['exact_signflip_p']:.8f}；同一变体18项K交互Holm p={interaction['holm_p_18']:.5f}。

## 7. 统计口径与证据边界

各阶段沿用原检验族：初轮Dot/Uniform为6项，K扫描Dot/Uniform为18项，MLP/Dot为24项，LN/MLP及GELU/MLP各24项。每个比较用相同Split配对，精确符号翻转枚举2^10组合，再做Holm校正；阶段之间不伪称存在事先预设的统一检验。四类主直接比较均没有校正后显著改善或下降。

配对t的95%区间是未做多重比较校正的描述性区间。另存的48项LN/GELU合并Holm敏感性分析中，n=10使双侧精确p最小为2/1024，首项最小校正p=0.09375，因此该分析在0.05下本身不能拒绝首项；不能用它证明没有效应。

所有Split来自同一张图且存在重叠，每Split只有一个训练seed；划分随机性与优化随机性没有充分分离。跨图均值、改善组数和门控熵用于描述，不能替代独立图或额外seed验证。累计加入hop并重训测量的是可用范围变化，不是固定模型中某一hop的因果贡献。

## 10. 机制观察与失败案例

原MLP通常让Texas/Wisconsin/Cornell的门控更集中，但Squirrel更均匀仍退化；Chameleon更均匀而改善，Actor更集中而改善，不能用“越尖锐越好”或“越均匀越好”概括。

LN在三个小图降低最终score尺度、提高平均门控熵，但准确率没有稳定提高；LN在Chameleon反而使路由更集中。GELU在多个小图及Actor上提高score尺度、降低熵，同样不是普遍有效。隐藏向量做LN不保证最终Linear的分数尺度固定，也不保证softmax不饱和。

主要负例包括LN的Texas K4 −2.63 pp、Cornell K4 −2.11 pp，以及GELU的Wisconsin K1 −1.18 pp、Texas K4 −0.79 pp（均相对原MLP）。有效梯度和更新记录可排除模块未训练；它们不能排除优化难度、过拟合或归纳偏置差异。部分小图训练/验证缺类、测试节点少，波动较大；更大的K也未呈一致收益。

本系列没有据测试结果单方调MLP宽度、温度或训练预算，没有运行LN+GELU组合。较高hop权重不直接代表更大分类贡献，特征cosine只是过平滑代理。完整诊断见 [原Dot/MLP机制分析](docs/08_mechanism_analysis.md) 与 [LN/GELU详细报告](MLP_COMPONENT_REPORT.md)。
